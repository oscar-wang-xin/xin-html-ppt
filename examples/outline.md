# 示例大纲 / Sample outline

这是一份用来试跑技能的**输入样例**，不是成品。下面所有数字都是占位值，正式使用请换成真实数据并标注来源。

主题：中小企业知识中台落地路径
副标题：从找不到，到用得上

## 页面清单（10 页）

1. 封面 —— 主题、副标题、日期
2. 目录 —— 今天讲三件事
3. 第一章 · 为什么 —— 章节过渡页
4. 现状与痛点 —— 四个数字把问题钉死（占位数据）
5. 数据图表 —— 季度沉淀文档量柱状图 + 知识来源构成环形图（占位数据）
6. 落地路径 —— 归拢 / 清洗 / 结构化 / 智能化 四阶段
7. 系统架构 —— 数据源 → 采集与清洗 → 知识中台 → 智能层 → 场景
8. 方案对比 —— 自建大平台 vs 轻量化起步
9. 配图位 —— 一图讲清闭环，可换信息图 / 架构图 / 插画
10. 结语 —— 收尾只讲一句

`docs/images/` 里的截图就是这份大纲跑出来的成品，可以对照着看。

## 试跑方式

把这份大纲交给已安装 xin-html-ppt 的 AI 工具，说「按这份大纲做 10 页 PPT」，或直接跑：

```bash
python scripts/new_deck.py --out . --title "中小企业知识中台落地路径"
# 没有 Python 时：node scripts/new_deck.js --out . --title "中小企业知识中台落地路径"
```
