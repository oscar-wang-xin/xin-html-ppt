# 示例大纲 / Sample outline

这是一份用来试跑技能的**输入样例**，不是成品。下面所有数字都是占位值，正式使用请换成真实数据并标注来源。

主题：中小企业知识中台落地路径
副标题：从找不到，到用得上

## 页面清单

1. 封面 —— 主题、副标题、日期
2. 我们到底卡在哪 —— 资料散、找不着、不敢用
3. 一个判断 —— 先把「找得到」做出来，再谈智能化
4. 三步走 —— 收拢 / 结构化 / 接上日常动作（配一条流程线）
5. 现状盘点 —— 四类资料的分布（配柱状图，占位数据）
6. 投入与产出 —— 一个季度的节奏（配折线图，占位数据）
7. 风险与边界 —— 权限、口径、维护责任
8. 收尾 —— 下次还能用的那份做法

## 试跑方式

把这份大纲交给已安装 xin-html-ppt 的 AI 工具，说「按这份大纲做 8 页 PPT」，或直接跑：

```bash
python scripts/new_deck.py --out . --title "中小企业知识中台落地路径"
```
